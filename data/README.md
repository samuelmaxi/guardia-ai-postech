# Dados

`maternal_health_risk.csv`: *Maternal Health Risk* (UCI Machine Learning Repository, id 863).

- Origem: https://archive.ics.uci.edu/dataset/863/maternal+health+risk
- Licença: CC BY 4.0
- Citação: Ahmed, M. (2020). *Maternal Health Risk* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5DP5D
- 1.014 linhas, 6 variáveis (Age, SystolicBP, DiastolicBP, BS em mmol/L, BodyTemp em °F, HeartRate) e o alvo `RiskLevel` (low/mid/high risk).
- Dados anonimizados e públicos, coletados em hospitais e clínicas de Bangladesh por meio de um sistema de monitoramento de risco baseado em IoT.

Alterações feitas no arquivo original: só foram removidos o BOM UTF-8 e as quebras de linha CRLF.
